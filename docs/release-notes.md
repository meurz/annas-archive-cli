Anna's Archive CLI 0.2.0rc5 is tagged on the current main branch, so
`git describe --tags` can resolve the version from main. Tags for rc1 through
rc4 retain the original commits used to build those releases.

Install this preview from PyPI:

```sh
uv tool install annas-archive-cli==0.2.0rc5
```

A Python wheel, source distribution and five native standalone archives are
available with SHA-256 checksums and GitHub build attestations.
The standalone binaries are distributed without OS signing or notarization.
